# CyberSafe — REST API Specification

**API Version:** `v1`  
**Base Path:** `/api/v1`  
**Protocol:** HTTPS / JSON  
**OpenAPI Specification:** Available interactively at `/docs` (Swagger UI) and `/redoc` (ReDoc).

---

## 1. Authentication & Headers

| Header | Type | Description |
|---|---|---|
| `Content-Type` | `application/json` | Required for all JSON payloads. |
| `X-Request-ID` | `string (UUID)` | Optional. Generated by server if omitted, returned in response for tracing. |
| `Authorization` | `Bearer <token>` | Optional for guest mode; required for authenticated user profiles. |

---

## 2. Endpoints Summary

| Method | Path | Summary | Description |
|---|---|---|---|
| `POST` | `/api/v1/analyze` | Submit Content for Analysis | Primary entry point for analyzing screenshots, text, URLs, or files. |
| `GET` | `/api/v1/analyze/{id}` | Retrieve Past Analysis | Fetches previously generated analysis result by UUID. |
| `POST` | `/api/v1/preferences` | Save Default Preferences | Sets user persona and technical explanation preferences. |
| `GET` | `/api/v1/preferences` | Get Default Preferences | Retrieves currently configured preferences. |
| `GET` | `/api/v1/threat-categories` | List Threat Categories | Returns the 8 supported threat categories and metadata. |
| `GET` | `/api/v1/health` | Health Check | Service liveness and dependency status. |

## 3. Detailed Endpoint Contracts

### 3.1 POST `/api/v1/analyze`
Submits suspicious digital content to the 5-stage pipeline.

#### Request Schema:
```json
{
  "input_type": "text | url | screenshot | file",
  "payload": "string",
  "user_preferences": {
    "who_are_you": "student | professional | personal_user",
    "technical_level": "simple | detailed | technical",
    "focus_area": ["emails_messages", "websites_links", "account_security", "device_security", "network_security", "everything"]
  }
}
```

- `input_type` *(enum, required)*: Type of input being supplied.
- `payload` *(string, required)*:
  - For `text`: Plain text content of email, SMS, or message.
  - For `url`: Target web address (e.g., `https://secure-login-apple.com.co/verify`).
  - For `screenshot`: Base64-encoded image string or image data URI (`data:image/png;base64,...`).
  - For `file`: Base64-encoded file payload.
- `user_preferences` *(object, optional)*:
  - `who_are_you` *(enum, default: `personal_user`)*: `student`, `professional`, `personal_user`.
  - `technical_level` *(enum, default: `simple`)*: `simple`, `detailed`, `technical`.
  - `focus_area` *(array of strings, default: `["everything"]`)*: Topic focus areas.

### 3.2 GET `/api/v1/analyze/{id}`
Retrieves a previously computed analysis by its unique identifier.

#### Response (HTTP 200 OK):
Returns the same payload as `POST /api/v1/analyze`.

#### Error Response (HTTP 404 Not Found):
```json
{
  "error": "AnalysisNotFound",
  "message": "Analysis record '8f1a4e2b-5b31-4c12-9c1a-2894178a9c01' was not found or has expired."
}
```

## 4. Error Code Catalog

| HTTP Status | Error Code | Description |
|---|---|---|
| `400 Bad Request` | `InvalidPayload` | Malformed JSON or unsupported input structure. |
| `400 Bad Request` | `SSRFBlocked` | Target URL resolved to an internal, loopback, or private cloud metadata IP. |
| `422 Unprocessable` | `UnsupportedFileType` | Uploaded file extension or magic bytes not supported. |
| `422 Unprocessable` | `PayloadTooLarge` | Payload exceeds 15MB limit. |
| `429 Too Many Requests` | `RateLimitExceeded` | Submission quota for the IP or token has been exhausted. |
| `500 Internal Error` | `PipelineError` | Unhandled error in security pipeline; degraded response served if possible. |
